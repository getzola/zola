# NNNN — <decision, as a statement>

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context

What forced the choice. The constraint, the measurement, or the failure that
made the status quo untenable. Keep it factual; a reader should be able to check
every claim.

## Decision

What was decided, in the present tense. One paragraph.

## Alternatives

What else was considered and why it lost. An alternative with no stated reason
for rejection means the decision was not really made.

## Consequences

What this makes easy, what it makes hard, and what it forecloses. Include the
costs — a record that lists only benefits is advertising.

## Evidence

Benchmarks, profiles, code references, test results. Link result files under
`benchmarks/results/` rather than pasting numbers without provenance.

## Enforcement

If the decision is mechanically checked, name the check and what its failure
message tells the next person to do. If it is not checked, say so.
